## Task 3: Implement Supplier Management

# Description

- Create a supplier management module that allows businesses to maintain supplier records and associate inventory products with their suppliers.

# Requirements

- Create a Supplier model with name, contact information, address, and status.

- Implement APIs to create, view, update, and deactivate suppliers.

- Allow products to reference one or more suppliers where appropriate.

- Add supplier search and filtering.

- Display supplier details on relevant product pages.

- Prevent deletion or deactivation from unintentionally breaking existing inventory records.

# Acceptance Criteria

- Authorized users can manage supplier records.

- Products can be associated with valid suppliers.

- Supplier details are displayed consistently.

- Existing product records remain valid when a supplier is deactivated.
